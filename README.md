# O.status

**O.status** is a clean and lightweight Android status bar customization app developed by **CATCHINGL**.

Customize your Android status bar with cellular signal and Wi-Fi indicators, with adjustable size and positioning.

## Features

- Custom cellular signal indicator
- Custom Wi-Fi indicator
- Adjustable indicator size
- Adjustable horizontal and vertical positioning
- Clean and minimal design
- Lightweight Android app
